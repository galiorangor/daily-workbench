🌱 养生顺序
先把顺序记住：第一步让大便成形，第二步把脾胃动力提起来，第三步才是慢慢补气血。顺序对了，吃进去的东西才有机会变成精神、脸色、手脚的温度。
当前阶段：第一步 · 让大便成形
📋 我的体质档案
• 身高 166 cm ｜ 体重 103.5 斤（偏瘦，BMI 约 18.8）
• 27 岁 ｜ 梨形身材（下半身偏多，上半身偏单薄）
• 最近戒零食后瘦了 2 斤，胸也跟着小了 → 目标：上半身饱满、腿细一点，不求体重掉
• 多炎症背景：结肠炎、胃炎、过敏性结膜炎、慢性胰腺炎、慢性甲状腺炎、慢性咽喉炎、毛囊炎、脂溢性皮炎、神经性皮炎、过敏性/接触性皮炎、慢性荨麻疹
⚠️ 多炎症体质：加餐和补养都要「低敏、抗炎、温软」，避开高糖、油炸、辛辣、冰冷和常见发物，别为了饱满反而点火。
🍽️ 每日三餐计划
脾胃要的是「温、软、定时、七分饱」。下面给的是方向，不是死规矩，按自己食堂和厨房灵活调。
🌅 早餐（自己做 · 温养为主）
• 主食：山药小米粥 / 南瓜粥 / 莲子芡实粥，轮换着来
• 蛋白：水煮蛋 1 个
• 加料：蒸山药、黑芝麻、红枣 2 颗（第二步后加）
• 忌：冰牛奶、冷面包、油炸、空腹冰饮
☀️ 午餐（食堂 · 会选是关键）
• 选温不选冷：打热菜，少碰凉菜、沙拉、冰饮
• 顺序：先菜 → 再肉/蛋 → 最后饭，不汤泡饭
• 蛋白要够：瘦肉 / 鱼 / 豆腐 选一样
• 主食粗细搭配，七分饱，不暴饮暴食
• 饭后至少站立/慢走 30 分钟，不要立刻坐下或躺下
• 忌：糖油混合物、奶茶、汤泡饭、吃撑、油炸/干锅/水煮/重辣
🌙 晚餐（自己做 · 七分饱）
• 结构：主食 + 熟菜，清淡少油
• 推荐：蒸鱼 / 炒时蔬 / 山药排骨汤（少量）
• 时间：睡前 3 小时吃完，不宵夜
• 忌：生冷、过饱、太晚吃、重口味
🍎 下午加餐（防掉秤 · 助上半身饱满）
你容易饱、又戒了零食，热量缺口自然下来了。想保住胸和上半身，得在下午补一顿温和加餐——不是饼干奶茶，是能接住的营养。
优先选这些（温、软、低敏、抗炎）
• 温豆浆 / 温牛奶 1 杯 + 核桃 2-3 颗：优质脂肪 + 蛋白，是激素和上身饱满的原料
• 蒸红薯 / 蒸山药 / 小份杂粮馒头：温软碳水，补热量不刺激脾胃
• 水煮蛋 1 个 / 一小碗豆腐脑（热）：便宜好吸收的蛋白
• 牛油果半个 + 一小片全麦饼：健康脂肪，饱腹又不火大
• 常温无糖酸奶（少量）：益生菌，但脾胃虚寒者别多、别冰
怎么吃才不白补
• 下午 3-4 点吃，别拖到饭前才塞
• 量小、分次：先一杯温豆浆 + 几颗核桃，饿了再补蒸薯类
• 配合第二步后的红枣桂圆、第三步的红肉/肝脏，上身才会慢慢回来
⚠️ 多炎症要避开的「假加餐」
• 高糖：饼干、蛋糕、奶茶 → 升糖快、促炎、反而掉肌肉
• 油炸 / 辣条 / 加工零食 → 点火，结肠炎胃炎咽炎都难受
• 冰饮 / 生冷水果 / 海鲜发物 → 伤脾胃、荨麻疹皮炎易反复
• 坚果若自身过敏则换黑芝麻糊、米糊替代
关于「腿细一点」
梨形想腿细，靠的是全身营养够 + 规律运动，不是饿。把下午加餐和三餐吃稳，配合八段锦、体态跟练（欧阳春晓瘦腿/芭杆系列），腿围会跟着整体状态改善，而上半身靠加餐把肉「补回该去的地方」。
第一步 · 让大便成形
进行中
核心思路
气血不足且大便不成形，第一步不是补血，而是先把大便养成形。脾胃先稳住，后面补气血才有意义。
每日行动（建议 7-10 天）
早餐：山药小米莲子芡实茯苓粥
煮成软一点、热一点的粥，每样一小把。先吃 7 天，让脾胃能接住。
养生茶：陈皮 + 茯苓 + 炒白术 + 炒薏米
陈皮理气，茯苓/炒薏米照顾湿，炒白术扶脾。用炒薏米，不是生薏米。
饭后慢走 10-15 分钟
不要马上坐着或躺下，让身体气机流动起来。
睡前揉腹 100 圈
手搓热，围着肚脐顺时针轻轻揉，慢一点、轻一点，让肚子松一点。
热水袋温腹部
温温地敷肚脐和小腹，不要烫。肚子凉、吃凉不舒服时特别合适。
晚上温水泡脚 15 分钟
脚冷明显的人加艾叶和生姜片，泡到脚暖即可，不要泡到一身汗。
忌口：生冷、油腻、过甜、过晚进食
吃凉易拉、水果多更散、晚上太晚吃第二天嘴里发黏，这些先收一收。
观察 3 个信号
① 大便是否比以前成形一点；② 饭后胀是否轻一点；③ 早上起来嘴里是否没那么黏。先看这些，不要一上来就盯着脸有没有红润。
第二步 · 提升脾胃动力
待开启
核心思路
大便刚稳一点，不代表脾胃已经很强。这时候要做的是提动力，不是加负担。别急着上红枣、桂圆、阿胶、黄芪。
每日行动（建议 2-3 周）
山药小米粥继续，但不全天喝粥
气血不足的人，蛋白质一定要跟上，不能一天三顿都是粥。
早餐加鸡蛋，中午吃瘦肉/鱼/豆腐
晚餐有主食和熟菜。基础营养够了，气血才慢慢起得来。
山药党参莲子红枣两颗瘦肉煲汤
红枣两颗就够，不要一抓一大把。少量多次，看吃完舒不舒服。
养生茶：太子参 + 黄芪 + 陈皮 + 茯苓
太子参平和，黄芪补气，陈皮防补后堵住，茯苓继续照顾湿。黄芪别放太重。
按揉足三里
每天左右各按 3-5 分钟，按到酸胀就行。适合长期养脾胃。
艾灸辅助：中脘、足三里、关元
饭后不要马上灸，时间不要太长，温温的就行。舌苔黄腻、口苦、便臭的人不要自己乱灸。
继续饭后走动 + 揉腹
保持脾胃动力，不积食、不胀肚。
观察 4 个变化
① 大便基本成形；② 饭后不那么堵；③ 下午没那么塌；④ 胃口稳定。到了这个程度，再进入第三步。
注意
补气不是喝完马上兴奋才叫有效。如果一喝就口干、烦躁、睡不好，或者饭后更胀、大便更散，就先停下来，说明现在还不适合。
第三步 · 慢慢补气血
待开启
核心思路
脾胃接得住了，再真正养气血。前面做了那么多，不是不让你补，而是为了让你补进去的东西能留下来。
每日行动
食疗加养血：山药红枣枸杞瘦肉/乌鸡煲汤
红枣两三颗，枸杞一小撮就够了。汤可以喝，但肉也要吃。
瘦红肉、鸡蛋、深绿色蔬菜
补气血不只是红枣阿胶，蛋白质、铁、叶酸、维生素 B12 这些基础营养也要跟上。
动物肝脏一周少量一次
猪肝、猪血等一周 1 次即可，配合维生素 C 丰富的蔬菜，不需要天天吃。
养生茶：当归 + 黄芪 + 陈皮，少量
不是猛泡。刚从大便不成形走过来，脾胃不能再被滋腻压住，所以要加陈皮。
睡前揉腹 100 圈 + 搓脚底涌泉 100 下
揉腹让中间舒服，搓涌泉让脚底暖。气血虚的人晚上尽量别熬太晚。
早睡，23 点前入睡
晚上两点还不睡，这个顺序本身就错了。睡眠是造血的关键。
八段锦 + 体态跟练
运动让气血运行，肩背舒展也能帮助胸部得到更好的气血濡养。
⚠️ 关键提醒
大便不成形的人，别一上来就追阿胶、红枣、桂圆。不是这些东西不好，是你要先看自己接不接得住。吃完舒服、饭后不胀、大便不散、睡觉不受影响，才说明方向大概率是对的。
