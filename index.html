🎯 15分钟体态训练流程（Part 1 → 3）
P1
Part 1 · 放松紧张部位
5分钟 · 3个动作
▼
斜方肌放松拉伸：头向对侧轻压，停留 30 秒。
胸肌 doorway 拉伸：小臂贴门框，身体前倾打开胸腔。
猫牛式脊柱活动：配合呼吸拱背、塌腰各 8 次。
P2
Part 2 · 激活薄弱部位
7分钟 · 4个动作
▼
YTWL 肩背激活：俯卧位做 Y-T-W-L 各 10 次。
死虫式核心稳定：对侧手脚伸展，保持腰部贴地 12 次。
臀桥：脚与肩同宽，顶峰夹臀停留 2 秒，15 次。
俯身飞鸟：激活菱形肌与中下斜方肌，15 次。
P3
Part 3 · 整合训练
3分钟 · 1个动作
▼
靠墙站立：后脑勺、肩胛、臀部、小腿肚、脚跟贴墙，收下巴、沉肩，保持 3 分钟。
🌱 调理严格顺序
第一步养大便成形（7-10天）→ 第二步提升脾胃动力（2-3周）→ 第三步滋养补足气血。同步每日欧阳春晓肩颈训练疏通膀胱经、疏肝祛湿。顺序不可逆，禁止前期大量滋补阿胶、桂圆、牛油果、坚果等滋腻食物加重脾胃负担。

🍽️ 每日三餐计划
脾胃要「温、软、定时、七分饱」，不刻意节食，防气血持续流失。
🌅 早餐固定标配（温热软烂）
• 山药小米莲子芡实粥（每种一小把，熬软烂）+ 1 个鸡蛋白/全蛋 + 一小块原味馒头
• 禁止：冰水果、蜜豆包、生冷酸奶空腹吃
☀️ 午餐（食堂 · 会选是关键）
• 每餐温和主食 + 少量瘦肉/豆腐 + 绿叶蔬菜，七分饱
• 饭后至少站立/慢走 30 分钟，不坐不躺
• 忌：冰饮、冰箱直取、重酸辣、油炸甜食、大量精制面食、汤泡饭、吃撑
🌙 晚餐（七分饱，不晚吃）
• 温和主食 + 熟菜，清淡少油；睡前 3 小时吃完，不宵夜
• 拒绝暴饮暴食、乱吃摆烂；不刻意少吃节食

🚫 全天忌口清单
• 冰饮、冰箱直取食物、重酸辣、油炸甜食、大量精制面食、生薏米
• 滋腻补品全部暂停：坚果、阿胶、红枣、牛油果（第二/三阶段再逐步加）
• 水果常温、饭后少量浅尝
🍵 日间健脾祛湿养生茶（单一温和配方）
• 陈皮 3g + 茯苓 5g + 炒白术 3g + 炒薏米 5g，温水冲泡
• 喝后腹胀、大便更稀 → 立刻停用
🍎 下午加餐（防掉秤）
容易饱又戒了零食，热量缺口下来了。下午 3-4 点补一顿温和加餐——不是饼干奶茶。
第一阶段（大便未成形）：先不加坚果/牛油果
• 温豆浆 / 温牛奶 1 杯 + 蒸红薯 / 蒸山药 / 小份杂粮馒头
• 水煮蛋 1 个 / 一小碗热豆腐脑；常温无糖酸奶（少量，脾胃虚寒者别冰）
第二/三阶段才逐步加
• 原味坚果每日少量（不可一次大量）；牛油果半个小份
• 配合红肉/肝脏，营养补足后线条才慢慢回来
⚠️ 多炎症避开「假加餐」
高糖饼干蛋糕奶茶、油炸辣条、冰饮生冷海鲜发物 → 点火、促炎、掉肌肉。

进行中
核心：祛湿固脾，减少脾胃负担
每日饮食规则（严格执行）
• 早餐标配如上（山药小米莲子芡实粥+蛋+馒头）
• 全天忌口清单如上；水果常温饭后少量
• 每餐温和主食+少量瘦肉/豆腐+绿叶菜，七分饱，晚餐不晚吃
• 日间健脾茶：陈皮3g+茯苓5g+炒白术3g+炒薏米5g
每日居家健脾动作（固定流程）
饭后慢走 10-15 分钟
不坐卧、不躺下，减轻积食腹胀。
睡前揉腹 100 圈
手搓热，肚脐顺时针轻柔揉；小腹冰凉可温热水袋敷肚脐（温和不烫）。
每晚温水泡脚 15 分钟
脚冷加少量艾叶+生姜片，泡到微暖，禁止大汗淋漓。
同步肩颈疏通（欧阳春晓全套，每日1次）
• 晚间饭后半小时练欧阳春晓肩颈放松全套（10分钟），松解斜方肌、肩胛骨薄弱肌群
• 动作缓慢轻柔，不暴力拉扯；练习后热敷后颈后背10分钟
作息安神（解决2/5点半夜惊醒）
• 22:30 准时入睡，睡前1小时关手机；小米手表关抬腕亮屏
• 半夜惊醒坚决不看时间；腹式深呼吸平复，不胡思乱想结节/饮食/体检
阶段自检标准（达标进第二阶段）
① 大便成型、不黏马桶；② 饭后腹胀明显减轻；③ 晨起嘴里不发黏。不看脸色、体重、胸部状态，脾胃为先。
第二阶段 · 2-3周 提升脾胃动力
待开启
饮食升级调整
• 早餐山药小米粥保留，不再顿顿喝粥；三餐均衡补优质蛋白：鸡蛋、瘦牛肉、淡水鱼、嫩豆腐
• 温和食疗汤（每周2-3次）：山药+党参+莲子+2颗红枣+瘦肉煲汤

• 养生茶更换：太子参3g+少量黄芪+陈皮+茯苓；口干烦躁失眠立刻停

• 日常三餐蛋白拉满：瘦红肉、鸡蛋、深绿色蔬菜，每周少量动物肝脏一次补铁养血

🎓 Day 1 · 半导体产业链与商业模式
学习目标：画清产业链、分清前道/后道、搞懂四种商业模式、从采购视角判断供应商结构。
预计时间：30–45 分钟。
学习顺序：产业链全景 → 前道 vs 后道 → 四种模式 → 采购视角。
① 产业链全景
IC 设计 → 晶圆制造 (Front-end) → 晶圆测试 (CP, Chip Probing) → 封装 (Packaging) → 最终测试 (FT, Final Test) → 出货
阶段核心动作采购重点
IC 设计架构与电路设计EDA、IP 授权、流片 / 代工服务
前道制造硅晶圆上做出电路光刻 / 刻蚀 / 沉积设备与高价值备件
晶圆测试 CP切割前筛出坏 die探针卡 (Probe Card)、测试机 (Tester)、探针台 (Prober)
封装把 die 包起来、连引脚贴片 / 焊线 / 塑封机、基板、塑封料
最终测试 FT出厂前功能 / 性能测试测试机、分选机 (Handler)、测试座 (Test Socket)
采购视角：前道是 CAPEX 游戏（设备天价）；后道是 CAPEX + OPEX 混合（设备较便宜、耗材备件周转快）。你的主战场在后道。
② 前道 vs 后道：采购差异
维度前道 Front-end后道 Back-end
设备单价极高（EUV 光刻机上亿 USD）中等（焊线机几十万 ~ 百万 USD）
单源风险极高（ASML EUV 等）中等（K&S / Shinkawa 等可选）
备件特点高价值、长交期、需原厂认证种类多、消耗快、部分可国产替代
采购周期设备 12–24 月，备件 3–6 月设备 3–9 月，备件 1–8 周
供应商结构OEM 垄断 + 授权服务商OEM + 代理商 + 国产替代厂
经验映射类似整车大型产线投资更像 MRO + 工装夹具管理
③ 四种商业模式
IDM（Intel / Samsung / TI）：设计 + 制造 + 封测全做，采购量大、议价强，关键备件签维保合同 (Service Contract)。
Foundry（TSMC / SMIC）：只做前道，基本不直接买封装设备。
Fabless（Qualcomm / NVIDIA）：只设计，不买设备，买封测服务。
OSAT（ASE / Amkor / 长电科技）：专做封测，是封装设备 / 备件 / 耗材采购主力，国产替代机会大但关键工艺仍有单源风险。
④ 采购视角总结
1) 客户是谁决定买什么：IDM / Foundry 买前道，OSAT 买后道，Fabless 不买设备。
2) CAPEX vs OPEX 预算来源不同：设备走资本预算（项目制、长周期），备件 / 耗材走 MRO 流程（频繁补货）。
3) 单源 vs 多源：核心设备往往单源或双寡头，通用备件可引入第二供应商。
4) 你的汽车 MRO 经验直接可用：SAP 的 PR / PO / GR、供应商绩效、VMI 寄售、安全库存、ABC 分类逻辑完全一致，差异只在技术参数更细、认证周期更长。
📝 一页纸总结 + 关键词
产业链 = 设计 → 前道 → CP → 封装 → FT。主战场在后道，客户是 OSAT / IDM。核心能力 = 技术参数理解 + TCO 分析 + 供应链风险管理 + MRO 经验迁移。

封装Packaging / Assembly包 die 并连外部引脚

💼 采购案例
某 OSAT 扩产采购 10 台 Wire Bonder（焊线机）+ 1 年瓷嘴 / 劈刀 + 维保。问题：① 品牌平衡 K&S（交期长）vs Shinkawa（价格优）；② 瓷嘴消耗大，是否签 VMI 寄售降库存；③ 加热模块是否单源，需否二供；④ 设备走 CAPEX、瓷嘴走 OPEX，合同拆分还是打包谈折扣；⑤ 与汽车 MRO 采购 CNC 夹具 + 刀具逻辑类似，只是认证更严、交期更紧。
